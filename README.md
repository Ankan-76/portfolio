# Ankan Biswas - Professional Portfolio

![Portfolio Preview](./assets/home-preview.png)

Welcome to the source code repository of my personal portfolio website! This project showcases my skills, experience, and development projects. It features a modern, responsive design with dynamic 3D elements, glassmorphism UI, and smooth animations to provide a premium user experience.

## ✨ Key Features

- **Modern & Premium Design**: Custom UI utilizing a dark glassmorphism aesthetic with vibrant accent colors.
- **Interactive 3D Elements**: Dynamic hero section and 3D navigation components.
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop viewing.
- **Smooth Animations**: Engaging micro-interactions and scroll-reveals across all pages.
- **Comprehensive Sections**: Includes Home, About, Skills, Projects, Experience, Services, and Contact pages.
- **SEO Optimized**: Built with proper semantic HTML and meta tags for search engine visibility.

## 🛠️ Technology Stack

- **HTML5**: Semantic web structure.
- **CSS3 & Tailwind CSS**: Advanced styling, responsive utility classes, and custom animations.
- **JavaScript (Vanilla)**: Core logic, DOM manipulation, state management, and 3D rendering interactions.

## 🚀 Getting Started

To explore or modify this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ankan-76/portfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd portfolio
   ```
3. **Run a local server:**
   Since this is a static website, you can simply open `index.html` in your browser. For a better development experience with hot-reloading, use a local server like VS Code's Live Server extension, or a simple Python server:
   ```bash
   python -m http.server 8000
   ```
4. **View the site:**
   Open `http://localhost:8000` in your web browser.
